# ENG-PALMAS-SITE ☀️🏗️

## About the Project
This repository contains the source code for the institutional website of our family-run engineering and solar energy company, based in Palmas, Tocantins. 

The main goal of this project is to establish a clear and professional digital presence, providing potential clients with easy access to our services, company history, and contact information.

## Key Features
* **Service Overview:** Detailed presentation of our engineering and solar energy solutions.
* **Institutional Context:** Information about the company's background and mission.
* **Contact Section:** Straightforward ways for clients to reach out for quotes and inquiries.
* **Responsive Layout:** Basic structuring to ensure readability across different devices.

## Technologies Used
* **HTML5:** For the core structure and semantic elements of the web pages.
* **CSS3:** For styling, custom layouts, and visual identity.
